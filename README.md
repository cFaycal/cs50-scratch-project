# cs50-scratch-projectA  

Scratch project made for CS50's Problem Set 0. In this project you control Avery as she walks down a city street using the left and right arrow keys. As she walks, she encounters a $100 bill lying on the sidewalk. When she reaches it, the scene shifts to a close‑up where Avery picks up the bill and thinks aloud about the people she owes money to.
